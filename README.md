# ☕ Coffee Shop Sales Analysis

## Project Overview
This project analyses coffee shop sales data from January to June 2023 across three store locations: Astoria, Hell's Kitchen, and Lower Manhattan.

Using Microsoft Excel, I cleaned and analysed the dataset and developed an interactive dashboard to identify sales trends, product performance, and customer purchasing patterns.

## Tools Used
- Microsoft Excel
- Power Query / Excel data cleaning tools
- PivotTables
- PivotCharts
- Slicers

## Key Performance Indicators
- Total Revenue: $698,812.33
- Total Transactions: 149,116
- Total Units Sold: 214,470
- Average Transaction Value: $4.69
- Average Units per Transaction: 1.44

## Key Insights
1. Revenue increased significantly between February and June 2023.
2. Hell's Kitchen generated the highest revenue among the three store locations.
3. Coffee and tea were the leading revenue-generating product categories.
4. Sales activity was strongest during the morning hours.
5. Revenue varied across different weekdays.

## Recommendations
- Investigate the factors contributing to monthly revenue growth.
- Compare customer demand and purchasing patterns across store locations.
- Maintain adequate inventory of high-demand beverages.
- Optimise staffing during peak sales hours.
- Explore promotional strategies for lower-performing periods.

## Conclusion
This project demonstrates how Excel can be used to transform sales data into meaningful business insights that support data-driven decision-making.
